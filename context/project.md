# Proyecto: Reloj y Gastos Compartidos (Tin & Noel)

## Objetivo del proyecto
Construir una aplicación web muy simple inspirada en Splitwise para uso doméstico.

## Alcance del MVP
- Solo existen dos personas: Tin y Noel.
- No hay login.
- No hay grupos.
- No hay invitaciones.
- Todos los gastos se dividen 50/50.
- El objetivo es registrar gastos y mostrar el balance entre ambas personas.

## Reglas de desarrollo
- Implementar una única historia por vez.
- Antes de modificar código:
  - analizar el estado actual
  - explicar la solución propuesta
  - indicar qué archivos modificarás
  - esperar aprobación
- Después de implementar:
  - verificar que el proyecto sigue funcionando
  - actualizar docs/STATE.md únicamente si cambió el estado de implementación
  - actualizar context/decisions.md únicamente si se tomó una decisión permanente

## Prioridades
1. Simplicidad, legibilidad y velocidad de desarrollo.
2. No agregar funcionalidades futuras ni abstraer componentes sin necesidad.
3. No implementar varias historias en una misma iteración.
4. No inferir requerimientos no expresados.
