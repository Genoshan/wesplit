The project is a simple web app for shared expenses between two people (Tin and Noel).

**Core Rules:**
1. One story at a time.
2. No extra features (no login, no groups, no invites).
3. All expenses are split 50/50.
4. Simplicity over complexity: avoid unnecessary-refactoring or complex logic.
5. Development workflow: Analyze -> Explain -> List Files -> Approval -> Implement -> Verify.
