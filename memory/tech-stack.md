The project uses a local architecture:
- **Frontend**: HTML, CSS (custom variables), and Vanilla JS.
- **Backend**: Node.js with Express.
- **Database**: SQLite for persistent storage of expenses.
- **Integration**: Fetch API to connect the frontend to the local server on port 3000.
